# 🎬 CineScope - Movie Search App

A modern and responsive movie discovery web application built with **HTML**, **CSS**, and **JavaScript** using the **TMDB (The Movie Database) API**.

Users can explore trending, popular, top-rated, and upcoming movies, search for any movie, view detailed information, and save their favorite movies locally.

---

## 🚀 Features

* 🔥 Trending Movies
* 🎬 Popular Movies
* ⭐ Top Rated Movies
* 🎥 Upcoming Movies
* 🔍 Search Movies
* ❤️ Add & Manage Favorites
* 🌙 Dark / Light Theme
* 📄 Movie Details Modal
* 💾 Local Storage
* 📱 Fully Responsive Design
* ✨ Smooth Animations
* 🚫 Error Handling
* ⏳ Loading Screen

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/cinescope.git
```

### 2. Open the Project

Open the project folder in **Visual Studio Code**.

### 3. Get a TMDB API Key

Create a free account on TMDB and generate an API key.

Replace:

```javascript
const API_KEY = "YOUR_TMDB_API_KEY";
```

with your own API key.

### 4. Run the Project

Open **index.html** in your browser or use the VS Code Live Server extension.
